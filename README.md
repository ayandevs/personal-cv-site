# 📄 Personal CV Website

## 📖 Description

A professional personal CV website designed to showcase personal information, skills, education, experience, achievements, and professional references in a clean two-column layout.

## ✨ Features

- Professional CV layout
- Personal profile and contact details
- Technical skills with progress bars
- Education and experience sections
- Hobbies with icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- jQuery
- Font Awesome

## ▶️ How to Run

1. Download or clone the project
2. Open the project in a code editor
3. Ensure the profile image is inside the "images" folder
4. Ensure all required files are included
5. Open "index.html" in a web browser
